# threads-auto (2단계: 텔레그램 버튼으로 골라서 쓰레드에 게시)

살림 고수 캐릭터가 핫이슈를 골라 100자 글, 사진, 쿠팡 후보 3개를 만들어
텔레그램으로 보내 줍니다. 버튼으로 형태와 상품을 고르고 승인하면, 예약 시간(07:00 / 11:00 / 18:00 / 21:00)에
쓰레드에 올라가고 쿠팡 링크와 대가성 문구는 첫 댓글로 달립니다.

## 하루 흐름
1. 게시 3~7시간 전에 초안이 텔레그램으로 도착 (새벽에 온 초안은 알림 소리 없음)
2. 버튼으로 형태(사진+쿠팡 / 사진만 / 쿠팡만 / 글만)와 상품 선택, ✅ 승인
3. 07:00 / 11:00 / 18:00 / 21:00 이후 첫 확인 때 게시 (승인 안 해도 자동 게시, ⏭ 건너뛰기를 누른 것만 안 올림)
4. `🚀 지금 게시`를 누르면 예약 시간을 기다리지 않고 바로 게시

글·사진 바꾸기
- `🔁 같은 이슈로 다시`: 이슈·사진·상품은 그대로, 후킹과 문장만 새로
- `🆕 새 이슈로`: 이슈부터 글·사진·상품까지 전부 새로
- `🖼 다른 사진`: 글은 그대로, 사진만 (제미나이 ↔ 무료 사진)
- 벤치마킹: 다른 계정 인기글을 캡처해 봇에 **사진으로** 보내면 글·조회수·잘된 이유를 읽어 저장하고, 다음 초안부터 그 형식을 참고 (state/benchmarks.json, 최근 30개)
- 직접 고치기: 초안 메시지에 **답장**으로 고친 글을 보내면 그 글로 바뀜 (500자까지)

영상·인용 글 (허락받은 영상만)
- 봇에 **영상(또는 링크) + 제품명 한 줄**을 보내면, 예약 글은 그대로 두고 **추가 초안**이 하나 더 만들어짐. 쿠팡은 제품명으로 검색. 그대로 두면 1시간 뒤(예약 글과 1시간 넘게 떨어진 때, 06~23시 안)에 자동 게시
  - 쓰레드 게시물 링크 → 그 글을 인용해서 올림. 인용 번호를 못 찾으면 글 아래 링크 카드로 올림
  - 구글 드라이브·드롭박스 공유 링크, mp4 주소 → 영상을 받아서 함께 올림 (200MB까지, 공유는 '링크가 있는 모든 사용자')
  - 영상 파일을 봇에 직접 보내기 (20MB까지, 메모는 영상 설명란에)
- **사진 + 주제**: 사진 설명란을 `글`로 시작해서 보내면(예: `글 전기포트 물때 구연산으로 없애기`) 그 사진과 주제로 추가 초안이 만들어짐 (Claude가 사진도 보고 씀). `글` 없이 보낸 사진은 벤치마킹 캡처로 처리
  - **여러 장**: 사진·영상을 한 번에 여러 개 골라 보내고 그중 하나의 설명란에 `글 제품명`을 쓰면, 전부 한 글에 넘겨 보기(캐러셀, 최대 20개)로 올라감. 확인 시간에 걸쳐 나뉘어 도착해도 같은 묶음이면 초안에 더해짐
- 메모 예: `360도 돌아가는 자석 충전 케이블` + 다음 줄 `출처: 판매자 OO (허락받음)` → 출처 줄은 글 끝에 그대로 붙음
- 추가 초안 버튼: `🛒 쿠팡 댓글` / `📝 댓글 없이`, `🔁 글만 다시`, `🚀 지금 게시`, `⏭ 건너뛰기`

실행 시각은 GitHub 예약 대신 무료 알람 서비스(cron-job.org)가 정해요. GitHub 예약은 몇 시간씩 늦거나 빠졌기 때문이에요.
- 초안 만들기: 한국 08·14·18·22시 (다음 게시 회차의 초안을 미리 만듦)
- 버튼 확인 및 게시: 한국 06:00~23:40 사이 20분마다
- 설정 방법: `알람서비스-설정하기.md` (프로젝트 파일)

## 파일 구성
| 파일 | 하는 일 |
|---|---|
| `prompts/persona.md` | 캐릭터·말투·금지 주제 (여기만 고치면 글 성격이 바뀜) |
| `src/trends.py` | 구글 트렌드·구글 뉴스 (+ 네이버·유튜브는 키가 있을 때만) |
| `src/writer.py` | Claude가 이슈 선택 + 글 작성 |
| `src/images.py` | 제미나이 사진 생성, 실패 시 Pexels |
| `src/coupang.py` | 쿠팡 파트너스 상품 후보 3개 검색 |
| `src/draft.py` | 초안 저장, 텔레그램 메시지·버튼 모양 |
| `src/telegram.py` | 텔레그램 전송, 버튼 눌림 확인 |
| `src/hosting.py` | 쓰레드가 가져갈 수 있게 사진·영상을 임시 공개 주소(72시간)에 올림 |
| `src/media.py` | 봇에 보낸 영상·링크 받기, 영상 내려받기 |
| `src/threads_api.py` | 쓰레드 게시 + 첫 댓글 |
| `src/make_draft.py` | 초안 만들기 (draft.yml이 실행) |
| `src/poll.py` | 버튼 반영 + 시간 된 초안 게시 (poll.yml이 실행) |
| `drafts/`, `state/` | 초안 기록과 버튼 확인 위치 (자동으로 저장됨) |
